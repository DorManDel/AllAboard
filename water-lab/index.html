Why these controls?

Scale changes the size of noise patches, not the screen pixels. Mix controls how much each layer contributes. Wind direction uses All Aboard's wind-TO convention (0° points north/up).

Performance contract

CPU canvas is deliberately low-resolution and throttled in this web lab. For Unity, move the full-screen color field to one simple GPU shader; keep CPU sampling only for ship motion and gameplay. FPS is browser display FPS, not GPU timing or Unity FPS.
