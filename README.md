# All Aboard — Mechanics Lab

A standalone browser playground for experimenting with the game feel of **All Aboard**: sailing, steering, wind, anchor, ocean effects, damage systems, friendly encounters and ship upgrades.

This repository is the **gameplay concept laboratory**, not the Unity game source.

- **Playable prototype:** [Open the Mechanics Lab](./index.html) (or enable GitHub Pages → Deploy from branch → main after merge).
- **Unity source:** https://github.com/Eilon343/AllAboard
- **Design:** Portrait, one-thumb, quick 1–3-minute runs; easy to control, hard to master.

## Scope
Browser-only experiments with explicit conceptual physics parameters; not production Unity code and not validated real-world marine physics.

All code and documentation in this repository are separate from the course Unity repository. Prototype experiments should be reviewed before adopting any mechanics into the Unity build.
